WHY THIS VERSION
- 3 French versions in the edition map: Camus 1886 is partial, Malandin 1986 is under
  copyright; Dorveaux is the only one eligible, a scholarly edition (rule 5.4).
- No reliable typed text: Gallica's copy (bpt6k1269988j) has only uncorrected automatic OCR
  (83%).
- English: empty (rule 6). The 3 English versions are all modern and under copyright, or
  partial.

RIGHTS: text public domain (Dorveaux died 1938); Public Domain Mark (Wellcome Collection).

FILE TYPES
- *_jp2.zip : one volume's page images (JPEG 2000), exactly as Internet Archive provides them.
- *_jpg.zip : one volume's page images (JPEG), as the library serves them page by page,
  packed without recompression.
- *_metadata.json / *_manifest.json : the library's own record of the item, unchanged.
- *_pages.csv : one row per page image with its checksum (for *_jpg.zip).
- *.xml : a typed text made by a scholarly project (TEI format).
- *.pdf : a scan delivered as a PDF.
