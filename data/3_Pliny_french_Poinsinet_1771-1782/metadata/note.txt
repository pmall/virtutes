WHY THIS VERSION
- 26 French versions in the edition map: 7 incomplete, 2 under copyright (Budé, Schmitt).
- No reliable typed text: the Wikisource transcription of Littré is marked "à corriger";
  the Remacle website states no licence or source.
- Scholarly editions that are also bilingual (rules 5.4 and 5.5): Poinsinet 1771-1782,
  Ajasson de Grandsagne 1829-1833, Littré 1848-1883. The earliest with a sharp-enough
  downloadable complete set wins (rule 5.6): Poinsinet. Its page is 26 cm tall (BnF-derived
  record; a dealer gives 25.2 cm), so 2500 px is about 245 px per inch, above the 225 required.
- It replaces Littré 1883, downloaded earlier on 12 November 2026; that folder was deleted.

RIGHTS: Public Domain Mark (Internet Archive).

FILE TYPES
- *_jp2.zip : one volume's page images (JPEG 2000), exactly as Internet Archive provides them.
- *_jpg.zip : one volume's page images (JPEG), as the library serves them page by page,
  packed without recompression.
- *_metadata.json / *_manifest.json : the library's own record of the item, unchanged.
- *_pages.csv : one row per page image with its checksum (for *_jpg.zip).
- *.xml : a typed text made by a scholarly project (TEI format).
- *.pdf : a scan delivered as a PDF.
