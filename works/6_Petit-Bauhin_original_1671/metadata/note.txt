HISTOIRE DES PLANTES DE L'EUROPE ("Petit Bauhin")
SELECTED: Lyon, 1671, 2 volumes, duodecimo (dedication signed by Jean-Baptiste de Ville,
according to the edition map).
SLOTS: ORIGINAL and FRENCH (the work was written in French). ENGLISH: none in the edition map.

FILES (all in the source/ folder next to this note, exactly as the libraries delivered them)
- bsb10300968_jpg.zip (+ bsb10300968_manifest.json, bsb10300968_pages.csv)
  What: volume 1 ([19] leaves, 442 pages), 502 page images, Bayerische Staatsbibliothek
  copy, call number Phyt. 25-1, about 970 x 1817 px.
- bsb10300969_jpg.zip (+ bsb10300969_manifest.json, bsb10300969_pages.csv)
  What: volume 2 (pages 445-866, [36] leaves), 514 page images, call number Phyt. 25-2,
  about 960 x 1818 px.
  Why here: the text will be typed from these scans, each passage keeping its page (rule 2).
  The library serves single pages; they are packed in one zip per volume, unchanged.

WHY THIS VERSION
- 17 editions in the edition map, all in French, all old printings, none with a typed text,
  none bilingual. So the earliest complete edition with a sharp-enough downloadable scan
  wins (rule 5.6).
- Earlier editions rejected: 1650 (no copy or catalogue record found anywhere); 1670 (only
  volume 1 can be downloaded; Wellcome's volume 2 is restricted).
- 1671 passes rule 4: complete (both volumes), free of copyright, downloadable in full. It is
  sharp enough at about 270 pixels per inch of page height (threshold 225), taking a 17 cm
  page (see NOT VERIFIED).
- It replaces the 1719 edition downloaded earlier on 12 November 2026, chosen when the
  threshold was an absolute 1,900 x 3,000 px; that folder was deleted.

NOT VERIFIED
- The page height of this copy: the library record gives none. 17 cm is the height recorded
  for the 1719 copy of the same format; at 15 cm the scan would be about 300 px per inch,
  so it passes the threshold either way within that range.

RIGHTS: text public domain; scans "No Copyright - Non-Commercial Use Only" (Bayerische
Staatsbibliothek, rightsstatements.org NoC-NC).

FILE TYPES
- *_jp2.zip : one volume's page images (JPEG 2000), exactly as Internet Archive provides them.
- *_jpg.zip : one volume's page images (JPEG), as the library serves them page by page,
  packed without recompression.
- *_metadata.json / *_manifest.json : the library's own record of the item, unchanged.
- *_pages.csv : one row per page image with its checksum (for *_jpg.zip).
- *.xml : a typed text made by a scholarly project (TEI format).
- *.pdf : a scan delivered as a PDF.
